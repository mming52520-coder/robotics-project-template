# Contributing

Contributions should keep this repository generic, reproducible, and safe to publish.

## Requirements

1. Confirm ownership and redistribution rights.
2. Use only synthetic, public, or explicitly redistributable examples.
3. Preserve the default simulation or non-actuating safety boundary.
4. Keep templates concise and technology-neutral.
5. Run the validation commands in `README.md`.

Pull requests must explain the problem, changed behavior, verification evidence, and any safety, privacy, licensing, or compatibility impact.

By contributing, you agree that your contribution is licensed under Apache License 2.0.
