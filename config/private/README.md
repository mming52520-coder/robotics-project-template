# Private configuration

Keep local, customer, site, device, network, and credential-bearing configuration here. The directory is ignored except for this notice.

Project hardware selection notes, received protocol documents, and protocol-intake
notes may also live here. Keep requirement and interface IDs in the public trace;
keep actual product and device facts here. See `docs/reference/hardware-protocol-handoff.md`.

Never copy private values into example configuration, logs, screenshots, issues, pull requests, or working memory.
